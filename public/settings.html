Crane fleet for lift planning
Adding or editing crane models

Crane specifications and load charts live in js/crane-data.js in the repository. Each model is a plain JS object with maxCapacity, boomLengths, a loadCharts table of configuration → boom length → radius → capacity (kg), and — where the crane has one — a jibCharts table of configuration → jib length → offset angle → boom angle → capacity (kg), since manufacturer jib charts are normally indexed by boom angle rather than radius. A top-level DATA_NOTES array flags any spots transcribed exactly as printed in the source PDF that are still worth a second look (e.g. duplicate tables or a highlighted cell in the manufacturer's own document). Edit crane-data.js with your crane's certified figures, commit, and every page picks up the change — there's no database migration involved.
