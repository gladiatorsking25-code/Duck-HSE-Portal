GOOGLE SHEETS PORTAL - START HERE

Do not double-click login.html or index.html.
Those files display the page but cannot start the private Google Sheets connection.

ONE-TIME SETUP
1. Install Node.js 22 or newer from https://nodejs.org/ if it is not installed.
2. In your Google Sheet, change Share > General access to Restricted.
   Keep the intended service account as an Editor.
3. Obtain that service account's JSON key and save it in a private folder outside
   this application. Enable the Google Sheets API in its Google Cloud project.
4. Double-click START-PORTAL.cmd once. It creates .env from the example if needed.
5. Open .env in Notepad. Set GOOGLE_APPLICATION_CREDENTIALS to the key's absolute
   path, keep APP_ORIGIN=http://localhost:3000 and set SHEET_PRIVATE_CONFIRMED=yes.
   Choose INITIAL_ADMIN_EMAIL and a NEW INITIAL_ADMIN_PASSWORD (12+ characters).
   Do not reuse the password exposed in the shared sheet.
6. Back up your sheet. In a terminal opened in this application folder, run:

   npm install --ignore-scripts
   npm run setup

   Setup replaces plaintext passwords with disabled accounts, creates the new
   administrator password hash, and adds the account and record-storage columns.
   It does not grant an existing blank subscription automatically.
7. Remove INITIAL_ADMIN_PASSWORD from .env after successful setup.

EVERYDAY USE
Double-click START-PORTAL.cmd and leave its window open.
In your browser, open http://localhost:3000/login.html
Choose Sign in and use your new administrator password.
Create an account is only for a new email address.

The public Google Sheets link alone is not a login endpoint. The private server
connection is required. This package does not need Firebase or Google Apps Script.

If startup reports a missing connection or sheet schema, follow its message.
If Windows asks which app should open .env, select Notepad.
Never upload .env or the service-account JSON file to a public website or chat.

Full instructions: GOOGLE_SHEETS_SETUP.md
