First-time setup (about 10 minutes, once)
  1. Open console.cloud.google.com and select the project this app's Firebase uses ().
  2. APIs & Services → Library: enable Google Drive API and Google Picker API.
  3. OAuth consent screen: add the scope …/auth/drive.file. While the app is in Testing, add each person who will upload as a test user.
  4. Credentials → Create credentials → OAuth client ID → Web application. Under Authorized JavaScript origins add this app's address () and, for local testing, http://localhost:3000. Copy the Client ID above.
  5. Credentials → Create credentials → API key. Restrict it to the Google Picker API and to this app's address. Paste it above.

Nothing here is a secret the way a password is — Google ties the Client ID to the origins you list — but restrict the API key anyway.
